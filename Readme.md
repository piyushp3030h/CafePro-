# CafePro – Cafe Billing & Inventory Management System

## About the Project

CafePro is a console-based Cafe Billing and Inventory Management System developed using C programming.

The application aims to simplify cafe operations by managing products, customer orders, billing, inventory and sales reports.

## Technologies Used

- C Programming
- GCC Compiler
- File Handling (Binary Files)
- Git and GitHub

## Features

- Product Management
- Customer Management
- Order Management
- Billing System
- Inventory Management
- Sales Reports

## Project Structure

- `include/` – Header files
- `src/` – Source code
- `data/` – Application data files
- `tests/` – Testing files
- `docs/` – Documentation
